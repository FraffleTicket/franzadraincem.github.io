# Franz Christian A. Adraincem — Portfolio

Static site (HTML/CSS/JS). Open `index.html` or deploy the folder to GitHub Pages / Netlify.

## What's new: Shopify case study
- A new "Ecommerce / Shopify" filter and a "Shopify Ecommerce Store — Lunara Home" project card in the Creative Portfolio.
- Clicking "View Case Study" opens the existing project modal in a wider layout with: overview, process, tools, screenshots grouped by section, skills, and final result.
- All case-study content lives in the `projects` array in `js/main.js` (the entry with `caseStudy:`). Screenshot paths are in the `SHOP_IMG` object right above it.
- Screenshots are in `assets/images/shopify-*.jpg`.

## Updating an existing GitHub repo
Replace/add: `index.html`, `css/style.css`, `js/main.js`, and the 10 new `assets/images/shopify-*.jpg` files.
