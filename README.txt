This folder is reserved for standalone icon files (e.g. custom SVG icons)
if you want to replace the emoji icons currently used in the Services and
Contact sections (see index.html and js/main.js).

Nothing in the current design requires a file here — all icons in the live
site are either emoji characters or inline <svg> markup already inside
index.html / js/main.js. This folder exists so you have a clear place to
drop new icon files later without restructuring the project.
